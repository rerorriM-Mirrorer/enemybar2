# PetBar agent entry point

Read WORKFLOW.md and TESTING.md directly from this folder's current GitHub branch before making changes. PetBar is incubated under the EnemyBar2 repository on the dedicated development branch; no EnemyBar2 running-addon files may be modified.

Keep commits small, record each tested/untested observation in TESTING.md, update documentation, and distinguish static verification from in-game tests. Include README.md, WORKFLOW.md and TESTING.md inside the installable PetBar folder when preparing testing packages.
